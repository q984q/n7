## Панель управления `/admin`

- Логин по умолчанию: `admin`
- Общего пароля нет. Задайте `N7_ADMIN_PASSWORD` и `N7_SESSION_SECRET` (случайный секрет не короче 32 символов) в окружении сервера. Старые сессии и реквизиты из архива недействительны.
- По умолчанию цены на витрине равны `0` («По запросу»). Для каждой из 72 позиций (включая каждую мощность прожектора) в `/admin` задаётся индивидуальная цена в `₸`.

## Запуск

```bash
npm ci
npm run build
npx next start -H 0.0.0.0 -p 3000
```

Требуется Node.js 22.13+ с `node:sqlite`. Заявки сохраняются в `leads.sqlite`, вложения в `uploads/` рядом. Подключите постоянный диск к `N7_DATA_DIR` (по умолчанию `data/`), а также обеспечьте сохранность `data/cms.json`. Архивный leads.json пуст; существующую внешнюю базу перед переключением необходимо перенести отдельно. Контакты и цены вводятся владельцем в CMS.
